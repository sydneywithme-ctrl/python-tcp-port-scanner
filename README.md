# Python TCP Port Scanner

# Project Overview
This is a Python TCP port scanner I developed for my Computer Security class. The program uses Python's socket library to identify open TCP ports on a target host.

## Features 
- Accepts an IP address from the command line
- Validates the IP address
- Checks if the host is reachable
- Scans for open TCP ports
- Displays the results

## Technologies & Tools
- Python 3
- Python Socket Library
- TCP/IP Networking
  
## How to Run
Run the following command:
```bash
python3 myNmap.py 127.0.0.1
```
## What I learned 
This program helped me understand how TCP connections work, how to use Python sockets, and why identifying open ports is important in cyber.

## Ethical Use 
This program is for educational purposes. Only scan systems you own or have permission to test.
